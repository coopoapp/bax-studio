Bax Studio — Privacy Policy

Last updated: October 17, 2026

Bax Studio is a private, single-user desktop tool operated by Araz Davudov (Baku, Azerbaijan). It is used only by its owner to upload videos that the owner produced to the owner's own YouTube channel («Архитектура Реальности») through the YouTube Data API. It is not offered to other users.

Data accessed

With the owner's consent via Google OAuth, Bax Studio uses the scopes youtube.upload and youtube.force-ssl to: upload video files, set titles, descriptions, tags, thumbnails and captions, add videos to the owner's playlists, and read the owner's own channel name and video processing status.

Data storage

The OAuth access/refresh token is stored only on the owner's own computer (file permissions restricted to the owner). Bax Studio has no server and no database. It does not collect, store, sell, share or transfer any personal data of YouTube users or third parties, and it does not access any other channel's data.

Third parties

Bax Studio uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Revoking access

Access can be revoked at any time at Google security settings; the locally stored token can be deleted from the owner's computer.
