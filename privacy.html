Bax Studio — Privacy Policy

Last updated: October 17, 2026

Bax Studio is a private, single-user desktop tool operated by Araz Davudov (Baku, Azerbaijan). It is used only by its owner to upload videos that the owner produced to the owner's own YouTube channel («Архитектура Реальности»). It is not offered to other users.

Use of YouTube API Services

Bax Studio uses YouTube API Services. By using Bax Studio you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (https://policies.google.com/privacy).

Information accessed, used and stored

With the owner's consent via Google OAuth, Bax Studio uses the scopes youtube.upload and youtube.force-ssl to: upload video files; set titles, descriptions, tags, thumbnails and captions; add videos to the owner's playlists; read the owner's own channel name and the processing status of the uploaded videos. No data of other YouTube users or channels is accessed.

The only stored item is the OAuth access/refresh token, kept on the owner's own computer with file permissions restricted to the owner. Bax Studio has no server and no database. It does not collect, sell, share or transfer any personal data to third parties, and it does not use cookies.

Data retention and deletion

Bax Studio stores no API Data other than the token above; the upload status it reads is shown once and not retained. The token can be deleted at any time by deleting the local token file, and access can be revoked at any time via the Google security settings page (https://security.google.com/settings/security/permissions). After revocation Bax Studio can no longer access the account. Any data requests can be sent to the contact below and will be handled within 7 days.
